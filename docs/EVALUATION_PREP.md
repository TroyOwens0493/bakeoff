# Bakeoff 2 evaluation preparation

## Project facts

- Project: bakeoff / Budget Together.
- Framework: Astro 7 with static rendering and TypeScript browser scripts.
- Database and backend: separate Convex project `troyteancum/bakeoff`, development deployment `notable-meadowlark-550`.
- Authentication: Better Auth, with a same-origin API proxy for cookies.
- Hosting: Netlify; GitHub production branch `SSR`.
- Live URL: https://bakeoff-troyowens.netlify.app.
- Specification: `Budget Together Spec.pdf`, with the agreed changes documented in the README.
- AI use: AI implemented the migration, tests, and project documents. The student's additional feature is a separate requirement.

## Measurements to collect

Use the same browser, device, connection, account data, and workflow for each stack. Record the commit and date. Check sign-in, opening a budget, saving a plan, filtering transactions, and receiving a shared update. Record build output size and any available build or page-loading measurements. Keep actual results separate from opinions. Do not enter invented numbers.

## Personal reflection prompts

Answer these in your own words after you build your feature:

1. Which Astro concepts did you learn?
2. Which parts were easy or difficult?
3. How did static rendering affect authentication and private data loading?
4. What tradeoffs did you observe compared with the first bakeoff?
5. What did AI produce, and what did you build yourself?
6. What failed during development, and how did you resolve it?
7. Would you select this stack for the final project? Explain your reasons.
